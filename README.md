# 3D 프린터 언더필 탐지 연구

> 산업공학 종합설계 팀 프로젝트 · 진행 중

## 문제와 목적

출력 중 촬영한 이미지로 3D 프린터의 **언더필**(재료가 부족하게 채워지는 현상)을 탐지하는 방법을 연구합니다. 실제 불량 데이터가 적은 상황에서 생성 이미지를 보충해도 검사 성능을 유지할 수 있는지 살펴보는 것이 장기 목적입니다.

## 데이터와 범위

기존 프로젝트 기록에는 정상 조건 2,000장과 언더필 조건 2,000장의 사진이 있습니다. 라벨은 출력 조건을 뜻하므로 모든 프레임에 결함이 눈으로 보인다는 뜻은 아닙니다. 각 클래스는 하나의 출력 실험에서 촬영돼, 같은 출력 안에서 나눈 평가만으로 새로운 출력에 대한 일반화를 검증할 수 없습니다.

지도교수님의 자료 공개 제한에 따라 원본·가공·마스킹·생성 이미지와 이미지가 포함된 묶음은 올리지 않습니다. 데이터, 가중치, 결과물도 이 저장소에 포함하지 않습니다.

## 내 역할과 협업

연속 촬영 이미지의 인접 프레임이 학습과 평가에 함께 포함되면 성능이 낙관적으로 측정될 수 있다는 문제를 제기했습니다. 일부 공통 평가에 시간 블록 교차검증과 30프레임 buffer를 적용하고, 학습·평가 사진 사이의 간격을 확인했습니다.

팀에서 준비한 STFPM과 DINOv2 기반 방법의 평가 사진·분할·전처리·지표를 정리하고, 가능한 조건에서 공통 사진을 기준으로 결과를 비교했습니다. STFPM의 기존 결과가 제 환경에서 재현되지 않았을 때 분할 차이의 가능성을 제기해 확인을 요청했으나, 성능 차이의 원인은 확정하지 않았습니다.

STFPM과 DINOv2 기반 팀 모델을 직접 개발한 것은 아닙니다. 프로젝트 코드는 팀 작업이며 코드 구현·집계·문서 정리에는 생성형 AI를 활용했습니다. 결과 파일과 평가 조건을 대조해 해석과 한계를 검토했습니다.

## 연구 진행과 한계

- 9~10월에는 관심 영역, 전처리·선별, 지도학습과 이상 탐지 방법, 평가 조건을 살펴봤습니다.
- 11월에는 적은 실제 이미지로 생성 모델과 품질 지표를 살펴보는 예비 작업을 진행했습니다. **생성 이미지를 분류기 학습에 보충했을 때 성능이 유지되는지는 아직 확인되지 않았습니다.**
- 지도·비지도 메인 접근, 게이트(판정 가능 여부를 보는 필터)와 최종 파이프라인은 팀 합의 전입니다. 이 저장소에 어떤 파일이 있다는 사실이 특정 방법의 최종 채택을 뜻하지 않습니다.
- 모델별 사진·분할·지표가 다른 결과는 직접 순위를 매기지 않습니다. 마스킹 면적이나 촬영 시점 등 결함 외 정보가 모델의 지름길이 될 가능성도 남아 있습니다.

자세한 흐름은 [시기별 연구 흐름](docs/RESEARCH_HISTORY.md)을 참고하세요.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `notebooks/local/` | 로컬에서 확보한 9~11월 Colab 노트북의 공개 사본 |
| `notebooks/drive_variants/` | 같은 이름의 로컬 사본과 셀 내용이 달랐던 Drive 노트북 사본 |
| `code/bundles/` | Colab용 묶음에서 분리한 Python 코드 사본 |
| `docs/` | 연구 흐름과 확인 범위 |

팀에서 코드와 노트북의 공개가 가능하다고 확인한 범위에서 정리했습니다. 노트북의 저장 출력·첨부·실행 횟수와 환경 메타데이터는 제거했습니다. 일부 노트북의 팀원 실명 텍스트와 일부 Python 파일의 주석·docstring은 공개 사본에서 비식별화했습니다. 변경된 노트북 셀의 복사·붙여넣기용 원문은 이 저장소가 아닌 로컬 보조 기록에 보관합니다. 원본 파일은 변경하지 않았습니다.

## 실행과 재현

이 저장소는 자료와 결과가 빠진 **코드 정리본**입니다. 노트북은 Drive의 입력 ZIP·사진·마스크·공통 코드·가중치 등에 의존할 수 있으며, 원래 Colab GPU와 런타임 설정 메타데이터도 제거돼 이 저장소만으로 곧바로 실행하거나 기존 결과를 재현할 수 없습니다. 필요한 자료·경로·환경을 별도로 확인해야 합니다.

코드와 노트북의 존재나 형식 점검이 실제 학습·평가 성공을 뜻하지 않습니다. 이 공개본을 정리하면서 학습·추론·실험 결과 재현은 수행하지 않았습니다. 사용하는 외부 라이브러리와 사전학습 모델의 이용 조건은 각각 확인해야 합니다.
